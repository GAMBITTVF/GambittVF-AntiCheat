GambittVF Anticheat - Projeto MVC com DAO e Swing

Como executar:
1. Extraia o ZIP.
2. Abra a pasta no IntelliJ ou qualquer outro de sua preferencia usando File -> Open.
3. Execute o arquivo sql/banco_gambittvf.sql no MySQL Workbench.
5. Adicione o mysql-connector-j-9.7.0.jar em File -> Project Structure -> Modules -> Dependencies.
6. Rode a classe Main.
